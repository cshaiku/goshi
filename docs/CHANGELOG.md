# Changelog

## 1.7.1 — 2026-10-15

- Build with Go 1.26.9 to satisfy the release standard-library vulnerability gate.
- Preserve graph protocol 1.1.0 and bridge 1.2.0 compatibility.

## 1.7.0 — 2026-10-15

- Track declared tool configuration, runtimes, SDK identity files and environment in graph fingerprints.
- Add shell completion hooks and shared protocol/native recovery checks on macOS, Windows and Linux.

- Add shared graph workflows with checkpoint recovery, selective resume, bounded context and explicit advisory AI diagnosis.

- Add graph protocol 1.1.0 / bridge 1.2.0: portable plans, scoped fingerprints, native report imports, bounded context, checkpointed execution and selective resume.
- Verify immutable evidence and explicit replay-safe retries. Optional AI diagnosis cannot qualify checks or apply repairs.
- Preserve native tool authority and standalone operation; execution remains limited to explicitly approved plans.

## Previous Work

### Project Origins

goshi is designed as a constrained, local-first model of AI-assisted tooling with maximum safety and auditability. The project explores bounded autonomy with:

- Explicit, machine-enforced understanding of scope and identity
- Pre-action safety validation
- Auditable filesystem proposals
- Deterministic, inspectable diagnostics
- Self-healing constraints limited to the tool's own repository

### Core Features (Pre-1.0)

- diagnostics-first execution pipeline with safety phases
- Two-phase, proposal-based filesystem model
- Path traversal protection and symlink handling
- Comprehensive environment detection
- Issue diagnosis with severity classification
- Action repair planning and execution
- Verification and dry-run support
